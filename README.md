# CompraCR — Android

Downloads of the CompraCR Android app (deals from Costa Rican stores). Get it from
[compracr.com](https://compracr.com) on your Android phone, or download the latest
[`CompraCR.apk`](https://github.com/CompraCR/buycr-rc/releases/latest/download/CompraCR.apk) from
[Releases](https://github.com/CompraCR/buycr-rc/releases).

Descargas de la app de CompraCR para Android (ofertas de tiendas de Costa Rica). Descárgala desde
[compracr.com](https://compracr.com) en tu teléfono Android, o baja el último
[`CompraCR.apk`](https://github.com/CompraCR/buycr-rc/releases/latest/download/CompraCR.apk) desde
[Releases](https://github.com/CompraCR/buycr-rc/releases).
